# Bundled themes

These are the color themes that ship with Ghostty, which collects them from the
[iTerm2-Color-Schemes](https://github.com/mbadolato/iTerm2-Color-Schemes) project
(MIT licensed). They are embedded into the `ghostty-profiles` binary so the tool
works without finding the Ghostty app bundle. Themes you put in
`~/.config/ghostty/themes/` override bundled ones of the same name.
